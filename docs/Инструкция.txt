ЦЕЛЬ

Провести меня от Этапа 0 до MVP по плану AltNet:
UI-каркас → TAL/профили (моки) → контентный слой (IPLD/IPFS-моки) → DM/Серверы (CRDT-журналы, CID-вложения) → .alt-браузер и конструктор сайтов → Почта/Репутация/Путешествия/Помощь/Профиль.
Никакой телеметрии наружу по умолчанию.

СХЕМА (высокоуровнево)

UI (десктоп/мобила)
→ E2E-шифр в приложении (X25519+ChaCha20-Poly1305, Ed25519, ротация ключей)
→ Профили: Анонимный | Приватный быстрый
→ TAL (автодетект каналов, метрики, hot-failover, политика приватности)
→ libp2p+PubSub (Noise/TLS, топики, CRDT-журналы)
→ Контент: IPLD/IPFS (CID/пины/квоты/зеркала/«холодное», RS-шардинг)
→ Приложения: .alt-браузер | DM | Серверы (чаты/голос/вики/файлы) | Почта | Конструктор сайтов | Путешествия | Репутация | Помощь | Профиль/Темы

ПРОФИЛИ/ПОЛИТИКИ

Анонимный:

libp2p через Tor/I2P;

публичный DHT Off;

mDNS Off;

Relay только свои;

payload PubSub всегда E2E;

без анонса приватных подсетей;

метрики только локально.

Приватный быстрый:

libp2p поверх Yggdrasil/WireGuard;

DHT Off/Local-only;

mDNS On в LAN/mesh;

Relay свои в оверлее;

payload E2E;

фильтр приватных подсетей;

метрики локально.

СЛОИ

L0 Каналы: Ethernet / Wi-Fi (ad-hoc) / модем / BLE (+возможен LoRa DTN).

L1 TAL: детект интерфейсов, RTT/Jitter/Loss/MTU, выбор путей, hot-failover (на MVP — моки).

L2 P2P: libp2p (Noise/TLS), PubSub (Gossipsub), E2E поверх.

L3 Контент: IPFS/IPLD, кеш+LRU, пины, общий pin-манифест, «холодное» (RS N/M).

L4 Приложения: DM (CID-вложения), Серверы, .alt-браузер, Конструктор (WYSIWYG→статический экспорт), Почта (адрес=ключ/алиас, TTL), Путешествия, Репутация, Профиль, Помощь.

ХРАНЕНИЕ

Квоты кеша: 5% по умолчанию; профили 1–2% / 5–10% / 20–50%.

Пины: локальные и групповые (подписанный манифест).

«Холодное»: RS-шардинг (N/M), подписанные метаданные.

Вложения: только ссылка-CID, медиа по требованию.

РЕПУТАЦИЯ

Жалобы/метки (спам/NSFW/вредное и т.п.), роли (модераторы/арбитры/участники), подписанные правила, апелляции, аудит-лог (хэши).
Жалобы шифруются до модераторов; публичны только итоговые метки.
Списки white/grey/black — подписанные манифесты.

UX

Вкладки: Лента (статус сети), Сообщения, Серверы, Путешествия, Браузер .alt, Почта, Создать сервер, Репутация, Помощь, Профиль.

Темы: светлая/тёмная + 3–5 акцентных.

Конструктор:

блоки (заголовок/текст/картинка/видео(CID)/кнопка/галерея),

предпросмотр,

экспорт ZIP (index.html + assets + manifest.json).

ПЛАН (ЭТАПЫ → КРАТКО)

Этап 0 Подготовка: каркас SPA (React+TS+Vite+Tailwind, shadcn/ui), навигация, темы, RU-локаль, утилиты, мок-слои.
DoD: сборка ок; вкладки/темы работают.

Этап 1 TAL+профили: интерфейсы TAL (метрики, политика путей, hot-failover — моки), переключатель профиля, «Состояние сети» в Ленте.
DoD: профиль меняет флаги DHT/mDNS/Relay и виджеты.

Этап 2 Контент: CID-хранилище, кеш+LRU, пины/квоты, общий pin-манифест, имитация RS (N→M).
DoD: файл→CID→кеш; квоты соблюдаются; сборка из M частей.

Этап 3 DM: CRDT-журналы (мок), списки/просмотр, вложения→CID→превью, реакции/стикеры/статусы.
DoD: отправка/получение; сквозной CID-поток.

Этап 4 Серверы: модель каналов/ролей, текст, вики (CRDT), файловая полка (CID/пины/загрузки), голос UI/WebRTC-заглушка, мастер «Создать сервер».
DoD: права скрывают каналы; совместное редактирование локально.

Этап 5 .alt+Конструктор: мини-адресная строка, история, «Опубликовать сайт»; палитра блоков, холст, свойства, предпросмотр, экспорт ZIP.
DoD: экспорт открывается в .alt-браузере.

Этап 6 Почта/Репутация/Путешествия/Помощь/Профиль до MVP.
DoD: ручные сценарии; сохранение настроек; метки видны.

КРИТЕРИИ UX/ПРОИЗВОДИТЕЛЬНОСТИ (MVP)

Навигация < 50 мс; списки виртуализованы (10k без просадок).

Экспорт статического сайта < 1 с (20 блоков).

Память < 300 МБ (без медиа-кеша).

Визуал: современный (Discord-like), тёмная/светлая, реакции/стикеры, тултипы.

ТЕСТ-МАТРИЦА (МИНИМУМ)

Профили: переключение применяет DHT/mDNS/Relay и меняет «Состояние сети».

Хранение: квоты, LRU-эвикция, неприкосновенность пинов; RS N=6 M=4 — сборка из 4.

DM/Серверы: текст, прикрепы→CID, превью; права скрывают; CRDT-конфликты мержатся.

Конструктор/.alt: все блоки, предпросмотр, экспорт ZIP, открытие.

Почта: compose, вложения (CID), папки, TTL-индикаторы.

Репутация: жалоба→решение→метка в UI.

ПОСТАВКИ/ОБНОВЛЕНИЯ

Десктоп: Win (.exe) / macOS (.dmg) / Linux (.AppImage/.deb).
Android — на втором этапе; iOS — позже как PWA.
Обновления: подписанные манифесты (несколько доверенных ключей), двухфазно; без телеметрии.

РИСКИ → МИТИГАЦИИ

Медленный Tor/I2P → локальные кластеры, адаптивный битрейт, добровольные реле в быстром оверлее.

Долговечность контента → общий pin-манифест, «холодное», подсказки «сохранить».

Модерация → подписанные правила, прозрачные журналы, автономия серверов.

Метаданные → минимизация по умолчанию; в Анонимном профиле «болтливое» выключено.
