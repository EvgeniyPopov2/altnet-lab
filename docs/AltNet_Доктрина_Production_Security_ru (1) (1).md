# AltNet — Доктрина «Production-ready и безопасность по умолчанию» (расширенная)
⟦ALTNET/ANCHOR: PROD_READY+SEC_BY_DEFAULT; E2E(X25519+ChaCha20-Poly1305,Ed25519); CDR+SafePreview; Telemetry=OFF; Profiles=Anon/PrivateFast; Gate=DoD=GREEN⟧

**Назначение:** зафиксировать обязательные принципы качества и безопасности для всех направлений платформы AltNet. Каждый сервис, экран и фича доводятся до уровня продакшн, а не прототипа. Безопасность и приватность — по умолчанию. Мобильная и настольная версии — функционально эквивалентны (parity), с адаптивным UI.

---

## 1) Золотые правила

1. **Production-ready всегда.** Бенчмарк по полноте — Telegram/Discord для коммуникаций, Яндекс.Браузер (UX) + Tor (безопасность) для .alt-браузера. Для чатов: редактирование/удаление/цитирование, реакции/эмодзи/стикеры, пересылка, вложения с превью (CID), голосовые, аудио-/видеозвонки, **видео-сообщения («кружочки»)**, статусы/онлайн/тайпинг, индикаторы доставки/прочтения, поиск, пины, черновики, **E2E** и **ротация ключей**, офлайн-очереди и ретраи.
2. **Безопасность по умолчанию.** Минимизация метаданных, наименьшие привилегии, защита по слоям (defense-in-depth), zero-trust, «secure-by-default». **Телеметрия — выключена по умолчанию.**
3. **Приватность и профили.** Два профиля: **Анонимный** (Tor/I2P, DHT off, mDNS off, PubSub payload всегда E2E, фильтр приватных подсетей; метрики — локально) и **Приватный быстрый** (Yggdrasil/WireGuard, mDNS в LAN/mesh, DHT off/локально, Relay — свои; payload E2E).
4. **Медиагигиена.** **Любой файл/медиа автоматически очищается от метаданных** и проходит CDR-конвейер. CID вычисляется от очищенного результата.
5. **Защита от вредоносного кода/контента.** Строгая валидация, анти-вирус/YARA (где возможно), лимиты, анти-zip-бомбы, SafePreview (iframe+CSP), санитизация HTML/MD.
6. **UX уровня продукта.** Современный UI, темы (светлая/тёмная + акценты), собственные стик-паки/эмодзи, доступность (a11y), локализация ru-RU, стабильные перформанс-цели и плавные анимации.
7. **Надёжность.** Offline-first, очереди/ретраи, идемпотентность, дедупликация, квоты и LRU-эвикция (пины неприкосновенны), локальный мониторинг и диагностика.
8. **Поставка и supply chain.** Подписанные обновления (несколько доверенных ключей), двухфазное применение, SBOM/lock, пиннинг зависимостей, воспроизводимые сборки (поэтапно), сценарии отката/канареек.

## 2) Обязательная полнота (эталон «Чаты»)

- **Сообщения:** создание/редактирование/удаление, цитаты, треды, реакции, эмодзи/стик-пак-менеджер (импорт/экспорт), форматирование (markdown-подмножество), поиск/фильтры, пины, черновики, мультивыбор, disable-link-preview, таймер автоудаления.
- **Медиа/вложения:** SafePreview, **CID**, фоновые загрузки, **авто-очистка метаданных**, CDR-конвейер, ограничения размера/типа/глубины архивов, загрузка «по требованию».
- **Голос/видео:** P2P-RTC поверх профиля, индикаторы связи/качества, переключение битрейта, **видео-сообщения** и **voice-messages**.
- **Приватность/безопасность:** **E2E** (X25519+ChaCha20-Poly1305, подписи Ed25519), ротация сессионных ключей, per-device ключи, кросс-подпись устройств, отзыв устройств, блокировки/мьюты, анти-спам/роли/модерация.
- **Надёжность:** офлайн-очередь, ретраи, дедупликация, восстановление после сбоев, квоты и LRU-эвикция без затрагивания пинов.

(Та же глубина — для Ленты, Серверов, Путешествий, .alt-браузера, Почты, Репутации, Поддержки.)

## 3) Доктрина безопасности

### 3.1 Криптография и ключи
- **E2E:** X25519 (кей-агримент) + ChaCha20-Poly1305 (AEAD), подписи **Ed25519**. Форвард-секретность: сессионные ключи + ротация; **Double Ratchet** — в план.
- **Multi-device:** per-device ключи, **кросс-подпись** устройств, список доверенных устройств, быстрый отзыв/ротация.
- **Секреты:** защищённые контейнеры ОС; пароли — Argon2id; шифрование «на диске» (где доступно).
- **Обновления:** подписанные манифесты несколькими ключами, проверка целостности, двухфазное применение/откат.

### 3.2 Транспорт/сеть
- **libp2p** (Noise/TLS), PubSub (Gossipsub), поверх Tor/I2P либо Yggdrasil/WireGuard по профилю.
- **Анонимный:** DHT off, mDNS off, Relay — только свои; payloads E2E; фильтры приватных подсетей; метрики локально.
- **Приватный быстрый:** Yggdrasil/WireGuard, DHT off/локально, mDNS в LAN/mesh; Relay — собственные; payload E2E.
- **Защита от утечек:** запрет прямых WAN-выходов для анонимного профиля, ACL по интерфейсам/CIDR, минимизация анонсов.

### 3.3 Метаданные и CDR-конвейер
1. **Sniff-валидация:** MIME + magic; белые списки типов.
2. **Анти-бомбы:** лимиты размера/кадров/страниц, глубина архивов, защита от zip-бомб.
3. **Антивирус/YARA:** карантин при срабатывании (stub → локальный движок).
4. **CDR/перекодирование:**
   - Изображения → PNG/JPEG/WebP, **удалить EXIF/IPTC/XMP/GPS**, новые превью.
   - Видео/аудио → безопасные контейнеры MP4/WebM/OGG, очистка тегов.
   - Документы → PDF-санитайз, Office → ODF/PDF-A без макросов.
   - Архивы → перепаковка без исполняемых битов/опасных симлинков; запрет SFX.
5. **CID от очищенного результата**. Исходник — не хранится (опция с явным согласием).

### 3.4 Песочницы и рендер
- **SafePreview:** изолированный iframe + строгий **CSP**; запрет inline-скриптов/стилей; allow-list для MIME/CID.
- **Санитизация HTML/MD:** whitelist-подмножество, запрет event-handlers/iframes.
- **Автовоспроизведение медиа:** off по умолчанию.

### 3.5 Роли, модерация, злоупотребления
- Роли: модераторы/арбитры/участники; права скрывают каналы/функции.
- Жалобы: шифруются до модераторов; публичны только итоговые метки; правила — подписанные; аудит-лог — хэши.
- Анти-спам/дозы: rate-limits, анти-бот-фильтры, локальные капчи, серые списки.

### 3.6 DevSecOps и supply chain
- **Security gates:** обязательные **код-ревью**, **Threat Modeling (STRIDE/kill-chain)**, **SAST/DAST**, **dependency-audit**, базовый **fuzz**.
- **SBOM/lock-файлы**, лицензии, воспроизводимость; секреты в CI — изолированы, с ротацией, least privilege.
- **Инцидент-менеджмент:** планы реагирования, ключи для отзыва, изолирование узлов/версий, журнал пост-мортема.

### 3.7 Логи/метрики/приватность
- Телеметрия — opt-in; по умолчанию off.
- Логи — локальные, без персональных данных/секретов; уровни; маскирование.
- Диагностика — экспорт отчёта вручную, без авто-отправки.

## 4) Критерии UX/перф/a11y
- Навигация < 50 мс; списки виртуализованы (10k без просадок); память < 300 МБ (без медиа-кеша); экспорт статического сайта < 1 с (20 блоков).
- Темы: тёмная/светлая + 3–5 акцентов; контраст/типографика — a11y; плавные анимации.
- ru-RU локализация — 100% пользовательских экранов.

## 5) Направления платформы — требования и DoD

### 5.1 Лента
**Функционал/UX**
- Комбинированная лента: подписки, серверные каналы, локальные новости сети; группировка по источникам/приоритетам.
- Виджет **«Состояние сети»**: TAL-метрики (RTT/Jitter/Loss/MTU), профиль, активные транспорты, hot-failover-индикаторы.
- Фильтры/поиск, пины, черновики постов; предпросмотр вложений (CID).
- Реакции/комментарии/репосты; отложенная публикация; черновики офлайн.
**Безопасность/приватность**
- Минимизация метаданных; CDR всех вложений; SafePreview; анти-фишинг-метки источников.
- В анонимном профиле — запрет внешних трекеров/встраиваний.
**Надёжность/перф**
- Инкрементальные фиды, Lazy-loading, кэш с квотами/эвикцией; офлайн-просмотр; ретраи.
**DoD**
- [ ] Лента быстрый скролл 10k+; [ ] Статус сети обновляется в реальном времени; [ ] Все вложения через CDR; [ ] Поиск/фильтры/пины готовы.

### 5.2 Сообщения (DM/группы)
**Функционал/UX**
- См. раздел 2 + каталоги чатов, треды, ответы; пересылка с сохранением ссылок-CID; реакции/эмодзи/стик-пак-менеджер.
- Голосовые/видео-кружочки; звонки 1:1 и групповые (RTC-UI).
**Безопасность**
- E2E + ротация; кросс-подпись устройств; настройки приватности; анти-спам/списки.
**Надёжность**
- Offline-first, очереди, ретраи; дедупликация; контроль квот.
**DoD**
- [ ] Редактирование/удаление/цитаты; [ ] RTC-звонки; [ ] E2E включён; [ ] CDR + SafePreview; [ ] офлайн-очереди.

### 5.3 Серверы (сообщества)
**Функционал/UX**
- Серверы как в Discord: роли/права, каналы (текст/голос/видео), **вики (CRDT)**, **файловая полка (CID/пины/загрузки)**.
- Мастер «Создать сервер»: правила/модерация/роли/категории; баннер/иконка; инвайты/правила доступа.
**Безопасность/модерация**
- Подписанные правила; шифрование жалоб до модераторов; аудит-лог (хэши).
- Набор политик: NSFW/спам/вредный контент — метки; апелляции.
**Надёжность**
- CRDT-схемы для совместного редактирования; офлайн-коммиты/мерджи.
**DoD**
- [ ] Права скрывают каналы/фичи; [ ] CRDT-вики; [ ] Файловая полка с CDR; [ ] Логи модерации подписаны.

### 5.4 Путешествия (каталог сообществ)
**Функционал/UX**
- Поиск/фильтры/категории; карточки серверов; быстрый превью контента (без загрузки лишних данных).
- Подписка/вступление; рекомендации без трекинга личности (on-device эвристики).
**Безопасность/приватность**
- Никаких внешних пикселей/скриптов; в анонимном профиле — только onion/ygg-адреса по политике.
**Надёжность**
- Локальный кэш каталога; подписи карточек; пины на важные манифесты.
**DoD**
- [ ] Каталог быстрый; [ ] Карточки подписаны; [ ] Рекомендации on-device; [ ] Политики профиля соблюдены.

### 5.5 Браузер .alt (современный как Яндекс.Браузер, безопасный как Tor)
**Функционал/UX**
- Вкладки, история, закладки/коллекции, менеджер загрузок, режим «читалка», поиск на странице, жесты/горячие клавиши.
- Поддержка схем **alt://**, **ipld://**, **ipfs://**, а также **https://** (clearnet). Обычные сайты — открываются; для анонимного профиля — через Tor.
- Изоляция сайтов (site-isolation), контейнеры по сайтам/профилям, профили вкладок (анон/приватный быстрый).
- Инструменты разработчика (безопасно изолированные), сохранение страницы в CID.
**Безопасность/приватность**
- HTTPS-only (для clearnet), HSTS/запрет mixed-content, DoH/DoT/резолв через профиль.
- Встроенный **anti-fingerprinting**, трекер-блокинг, cookie-контейнеры, запрет третьесторонних cookie по умолчанию.
- **Tor-подобные режимы:** «Новая личность» (сброс отпечатков/сессий), изоляция цепочек.
- Загрузки через **CDR**; предупреждения о потенциальной deanonymization.
**Надёжность/перф**
- Многопроцессность, ограничение памяти вкладок, «заморозка» фоновых, восстановление сессии.
**DoD**
- [ ] alt://, ipld://, ipfs:// и https://; [ ] Tor-совместимая анонимность; [ ] anti-fingerprinting/блок-тракеров; [ ] CDR для загрузок; [ ] site-isolation.

### 5.6 Почта (.alt-mail)
**Функционал/UX**
- Адрес = ключ/алиас, TTL и политики видимости; папки/теги; поиск; черновики; подписи.
- Вложения → **CID** + предпросмотр; квитанции доставки/прочтения (сквозные, без утечек).
- Опциональные мосты с SMTP/IMAP через шлюзы (с предупреждением о пониженной приватности).
**Безопасность**
- **E2E** по умолчанию; подписи/проверка; защита от фишинга (DKIM-подобные подписи для .alt-домена).
- CDR вложений; SafePreview; анти-спам.
**Надёжность**
- Offline-first; ретраи; дедупликация; квоты/LRU.
**DoD**
- [ ] E2E-почта; [ ] Вложения-CID+CDR; [ ] Поиск/фильтры/теги; [ ] Мосты предупреждают о рисках.

### 5.7 Репутация
**Функционал/UX**
- Жалобы/метки (спам/NSFW/вредное и т.п.), роли (модераторы/арбитры/участники), подписанные правила, апелляции.
- Публичны только итоговые метки; белые/серые/чёрные списки — подписанные манифесты.
**Безопасность**
- Жалобы шифруются до модераторов; аудит-лог (хэши); защита от манипуляций (Sybil-стойкие евристики на устройстве).
**DoD**
- [ ] Полный цикл: жалоба→разбор→решение→метка; [ ] Подписанные списки; [ ] Аудит-лог доступен.

### 5.8 Поддержка (Help/Support)
**Функционал/UX**
- Справочный центр (офлайн-пакет), поиск; «Задать вопрос» через .alt-mail/чат; FAQ.
- **Отчёт о проблеме**: локальный сбор диагностик (по согласию), анонимизация, упаковка в CID, отправка через профиль.
**Безопасность/приватность**
- Диагностика — без персональных данных; все журналы «очищенные»; удаление после отправки (по настройке).
**DoD**
- [ ] Офлайн-хелп; [ ] Безопасный отчёт; [ ] Канал обратной связи E2E.

### 5.9 «Летающая» иконка заметок (Global Notes Floating Tool)
**Функционал/UX**
- Всегда доступная плавающая кнопка/панель; быстрые **заметки с текстом, картинками, скриншотами** (скринер в приложении), чек-листы, теги.
- **Перетаскивание между вкладками/разделами**, вложения → CID; связывание заметки с сообщением/постом/ресурсом (deep-link).
- Поиск по заметкам; офлайн; экспорт/импорт; закрепление на экране.
**Безопасность/приватность**
- Снимки экрана/картинки проходят **CDR** и **удаление метаданных**; локальное шифрование заметок; E2E при отправке/шеринге.
**DoD**
- [ ] Скринер + CDR; [ ] Drag-and-drop между вкладками; [ ] Теги/поиск; [ ] Лок-шифрование и E2E-шеринг.

## 7) Примечания по реализации
- Вложенные медиа/файлы — только как **CID-ссылки**; скачивание по требованию.
- В анонимном профиле — принудительное отключение «болтливых» функций/встраиваний.
- .alt-браузер: clearnet-сайты — через Tor в анонимном профиле; предупреждения о deanonymization при отклонении политики.
- Tor/I2P мосты + obfs4: авто-детект/ротация, ручной выбор, списки доверенных источников мостов.
- Все экраны — доступность (a11y), локализация ru-RU; мобильная/настольная версия — паритет.
