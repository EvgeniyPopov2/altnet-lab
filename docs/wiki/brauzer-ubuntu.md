# Клиент AltNet с браузером для Ubuntu

На стенде каждая ВМ запускает свою копию AltNet Browser из `/opt/altnet-browser`. В окне Gecko находятся панель клиента и вкладки для сайтов. Графический рабочий стол может запустить приложение из меню или командой `altnet-browser`. В Ubuntu Server с Xorg, Openbox, xauth и dbus-run-session команда `sudo /opt/altnet-browser/start-console` открывает окно на экране ВМ из авторизованного сеанса SSH. Вход на Windows и настройки сетевых адаптеров для этого не требуются.

## Сборка и установка

Linux-пакет основан на официальной сборке Tor Browser 16.0.3 для x86_64. Сначала проверяют отдельную подпись Tor Project и отпечаток основного ключа `EF6E286DDA85EA2A4BA7DE684E2C6E8793298290`. Упаковщик проверяет закреплённый SHA-256 именно этого архива, применяет патчи адресной строки и интерфейса, добавляет локальную панель, транспорт и значок проекта. Отпечаток итогового пакета передают на ВМ по доверенному административному каналу. Выпуск стенда не имеет публичной подписи AltNet.

```sh
cd ui/altnet-ui
npm ci
npm run build
cd ../..
python3 scripts/assemble-ubuntu-browser.py --source /path/to/tor-browser-linux-x86_64-16.0.3.tar.xz --output /path/to/AltNet-Browser-linux-x86_64.tar.gz
sudo sh scripts/install-ubuntu-browser.sh /path/to/AltNet-Browser-linux-x86_64.tar.gz "$EXPECTED_SHA256"
```

Сценарий установки переключает каталоги программ атомарно. Предыдущая сборка сохраняется по выведенному пути. Перед обновлением закройте браузер обычным способом. При следующем запуске он обновит кэш кода Gecko.

## Данные

Профиль приложения находится в `${XDG_DATA_HOME:-$HOME/.local/share}/altnet/browser-profile`. Для резервной копии закройте приложение и скопируйте каталог целиком, включая `altnet-workspace.key`. Настройки приложения сохраняются в SQLite с AES-GCM и ключом владельца профиля. Черновики, локальные публикации и кэш CAR находятся в отдельном IndexedDB владельца приложения. Оба хранилища переживают закрытие приватного окна. Доступ к файлам учётной записи даёт доступ к её данным. При потере ключа восстановите его из резервной копии.

## Сетевые маршруты

- В быстром профиле участник вводит `ipfs://CID`. На Linux в `/etc/altnet-browser/mesh.json` администратор указывает `interface`, `source`, `peer` и числовой `port`. Оба адреса должны принадлежать Yggdrasil. Для соединения клиент привязывает IPv6-сокет к локальному адресу и интерфейсу.
- В анонимном профиле участник открывает `alt://onion/АДРЕС.onion/CID`. Приложение передаёт имя onion v3 системному Tor по SOCKS5 на `127.0.0.1:9050`. Обычные веб-вкладки используют этот же системный SOCKS с удалённым DNS. Быстрый профиль применяется к получению сайтов Alt/IPFS.
- Вкладка проверяет корневой CID и содержимое блоков и передаёт проверенную страницу изолированному просмотрщику. При открытии из нативной адресной строки в ней появляется внутренний адрес просмотрщика. Каноническая ссылка Alt/IPFS видна в шапке страницы.

## Публикация на выделенном узле

Для принимающей стороны достаточно клиента с Tor или настроенным маршрутом Yggdrasil. У публикующей стороны системный Tor направляет порт 80 выделенного onion-сервиса v3 на `127.0.0.1:17884`. В `/etc/altnet-browser/publisher.onion` помещают только публичный hostname этого сервиса. Ключ onion хранит системный Tor. Для раздачи используют службу из `systemd/altnet-browser-publication@.service` от имени пользователя конструктора. Для текущей конфигурации mesh слушатель принимает только доверенный адрес `peer`.

В конструкторе откройте «Раздача через Tor». Можно опубликовать сайт только через Tor или явно выбрать «Опубликовать через Yggdrasil и Tor». Второй вариант делает один CID видимым в обеих сетях. После закрытия окна выбранный CAR продолжает обслуживать служба. Для остановки используйте кнопку в этой же панели. Каталог активной публикации — `~/.local/share/altnet/published-car`.

## Приёмка

`tests/ubuntu-workspace.py` запускает установленный Gecko с отдельным новым профилем. Он проверяет NoScript, настройки SOCKS, отображение статуса и восстановление настроек, черновика, публикации и двоичной записи CAR после штатного выхода. Для теста сети передайте `--profile`, `--address` и ожидаемый `--title`. Тест вводит адрес в нативную строку, проверяет текст внутри изолированного фрейма и сохраняет PNG. `--publish-title` публикует тестовую страницу с узла через конструктор. `--inspect-publication` читает ссылки текущей публикации.
