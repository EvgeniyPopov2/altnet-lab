# Как попробовать интерфейс на Windows

Это запуск версии для разработки, а не установка готовой программы. Доступ к интернету или функционирование сети AltNet сам по себе он не настраивает.

## Что понадобится

- Windows с установленным Node.js и npm.
- Локальная копия проекта и установленные зависимости интерфейса.
- PowerShell и обычный браузер на том же компьютере.

Для рабочей копии, обнаруженной при проверке 22 ноября 2026 года, выполните в PowerShell:

```powershell
npm.cmd --prefix "H:\CodexData\Projects\altnet\altnet-lab\ui\altnet-ui" run dev -- --host 127.0.0.1
```

Если проект находится в другом месте, замените путь на путь к папке `ui\altnet-ui` вашей копии.

В открывшемся окне найдите строку `Local:` и откройте указанный в ней адрес в браузере на этом же компьютере. Если порт 5173 занят, адрес может отличаться. Пока вы пользуетесь интерфейсом, оставьте PowerShell открытым. Для остановки вернитесь в это окно и нажмите `Ctrl+C`.

## Если страница не открылась

1. Убедитесь, что в PowerShell появилась строка `Local:` и после неё нет сообщения об ошибке.
2. Скопируйте адрес из строки `Local:` целиком и откройте его в обычном браузере Windows. Встроенный браузер другого окружения может не иметь доступа к серверу на вашем компьютере.
3. Если PowerShell сообщает, что `npm.cmd` не найден, установите Node.js с npm из официального источника и откройте PowerShell заново.
4. Если сообщается, что не найден Vite или другие зависимости, попросите разработчика проверить установку зависимостей по `package-lock.json` и доступ к реестру npm.
5. Если ошибка осталась, передайте разработчику текст ошибки или снимок окна PowerShell. Не передавайте секретные ключи, пароли и личные данные.
