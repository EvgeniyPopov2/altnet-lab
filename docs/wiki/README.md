# AltNet — руководство пользователя

**Состояние: разрабатывается.** Сейчас доступен прототип интерфейса и экспериментальные переносимые сборки для Windows и Linux. Подписанного выпуска и готовых приложений Android и iPhone пока нет. Вики будет дополняться по мере появления и проверки работающих функций.

AltNet задуман как приложение для общения, обмена файлами, сообществ и сайтов. Оно должно работать через сеть участников и давать выбор между анонимным и приватным быстрым профилями. Описание целей проекта не означает, что эти возможности уже работают.

## Важное ограничение

Текущий интерфейс предназначен для разработки и демонстрации. Пока нельзя считать, что сообщения действительно доставляются другому пользователю, а выбор профиля обеспечивает анонимность или сквозное шифрование. Не используйте прототип для личной переписки и важных данных.
