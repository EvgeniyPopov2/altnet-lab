# Материалы дизайна AltNet

Получены из открытого пользователем проекта Kimi Design 23 ноября 2026 года.

- `altnet-kimi-redesign.fig` — экспорт всех страниц выбранного макета интерфейса в формате Figma. Доступность всех слоёв, ссылок и состояний после импорта ещё не проверена.
- `altnet-kimi-logos-psd.zip` — экспорт вариантов логотипа: четыре страницы PSD и шрифт Manrope. Выбранный значок «Самолётик-A» извлечён из слоя `logo-4` первой страницы и сохранён в `ui/altnet-ui/public/altnet-logo.png`.
- Ссылка на исходный проект: [макет интерфейса](https://www.kimi.ai/design/project/1a2048b6-9d92-817f-8000-0e71c4f2c469?canvasId=altnet-redesign.kui), [варианты логотипа](https://www.kimi.ai/design/project/1a2048b6-9d92-817f-8000-0e71c4f2c469?canvasId=altnet-logo-variants.kgraphic). Для открытия может потребоваться учётная запись Kimi.

## Что выбрано

Референс значка — фиолетовый квадрат со скруглёнными углами и белым самолётиком, вариант «Самолётик-A» на первой странице вариантов. Другие варианты с обозначениями P1–P4 являются отдельными предложениями и не подменяют выбранный пользователем вариант.

В интерфейсе видны мобильные макеты чатов, диалога, сообщества, центра безопасности, профиля, знакомства с приложением, выбора профиля, авторизации, почты, письма, браузера и репутации. Экспорт интерфейса также предназначен для остальных страниц исходного макета; состав и точность экспорта нужно проверить при импорте.

**Важно:** цифры безопасности и сообщения о защищённой сети на концепте — элементы дизайна, а не подтверждённые функции. В рабочем приложении их можно показывать только при наличии реальных проверяемых данных. Изображения из макета перед выпуском требуют отдельной проверки прав. Шрифт Manrope из архива содержит сведения об авторах и ссылку на OFL; соответствующий текст лицензии сохранён рядом со шрифтом в приложении.
